1. PROJECT OVERVIEW
================================================================================

The objective of this project was to perform end-to-end data cleaning using
Microsoft Excel Power Query. Raw business datasets often contain missing values,
incorrect data types, duplicate records, unnecessary columns, inconsistent
formats, errors, and structural issues that make analysis difficult.

This project demonstrates how Power Query can be used as an ETL (Extract,
Transform, Load) tool to automate the process of cleaning and transforming
raw datasets into structured, reliable, and analysis-ready data.

Instead of manually editing spreadsheets, Power Query records every
transformation step, allowing the cleaning process to be refreshed whenever
new data is added.

================================================================================
3. ETL PROCESS FOLLOWED
================================================================================

Extract

- Imported raw Excel datasets into Microsoft Power Query.
- Loaded source tables for preprocessing.

Transform

Several transformation techniques were applied depending on the structure of
each dataset.

Load

After completing the cleaning process, the transformed data was loaded back
into Excel for further analysis, reporting, or dashboard creation.

================================================================================
4. DATA CLEANING OPERATIONS PERFORMED
================================================================================

Throughout this project, multiple Power Query transformations were performed.

A. Data Import
----------------
• Imported raw Excel data into Power Query.
• Verified source structure.

B. Data Type Management
------------------------
• Changed incorrect data types.
• Converted columns into Text, Whole Number, Decimal Number and Date formats.

C. Data Reshaping
------------------
• Transposed tables.
• Promoted first row as headers.
• Filled down missing values.
• Split columns using delimiters.
• Merged columns.
• Reordered columns.
• Unpivoted selected columns.

D. Data Cleaning
-----------------
• Removed unnecessary columns.
• Renamed columns for consistency.
• Filtered unwanted rows.
• Sorted records.
• Replaced inconsistent values.
• Removed errors.
• Standardized column names.

E. Custom Transformations
---------------------------
• Added custom calculated columns.
• Applied multiple filtering conditions.
• Improved dataset consistency.
