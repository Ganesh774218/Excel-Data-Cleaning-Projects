# Excel Power Query Data Cleaning Project

## Project Overview

Data preparation is one of the most important stages of any data analysis workflow. Raw datasets often contain inconsistencies, missing values, formatting issues, unnecessary columns, duplicate records, and structural problems that make analysis difficult.

This project demonstrates a complete data cleaning workflow using **Microsoft Excel Power Query**. The objective was to transform raw datasets into clean, structured, and analysis-ready data by applying various ETL (Extract, Transform, Load) techniques.

The repository showcases practical Power Query transformations commonly used by Data Analysts and MIS Analysts while preparing business data for reporting and dashboard development.

---

# Objective

The primary objective of this project was to:

- Import raw datasets into Power Query
- Clean inconsistent and unstructured data
- Standardize data formats
- Remove unnecessary information
- Reshape datasets
- Handle missing values and errors
- Prepare analysis-ready data for reporting

# Data Cleaning Techniques Applied

During the project, multiple Power Query transformations were performed, including:

### Data Import
- Imported raw Excel data into Power Query

### Data Type Transformation
- Changed column data types
- Converted text, numbers and dates into appropriate formats

### Data Reshaping
- Transposed tables
- Promoted first row as headers
- Filled down missing values
- Split columns using delimiters
- Unpivoted selected columns
- Merged multiple columns
- Reordered columns

### Data Cleaning
- Removed unnecessary columns
- Renamed columns
- Replaced inconsistent values
- Applied multiple filters
- Sorted records
- Removed error values

### Custom Transformations
- Added calculated custom columns
- Standardized column naming conventions
- Prepared datasets for business analysis
